Comportamento Ativo da ECU

O simulador responde a pedidos Mode 01, 02, 03, 04, 07 e 09. A falha P0301 é reportada no Modo 03 com o bit MIL ativo (0x81). O Modo 02 fornece freeze frame completo gravado em ciclo. Comandos Mode 04 limpam o código temporariamente até novo disparo de carga.

help_center Como Testar a Aplicação
1
Validar em Dados ao Vivo Aceda à página 'Dados ao vivo'. Arraste o slider de RPM acima e comprove a sincronização imediata dos gráficos e mostradores de telemetria.
2
Testar Limpeza de Avarias Abra a aba 'Diagnóstico' para inspecionar o código P0301 ativo. Use a opção 'Apagar Códigos' para emitir o pacote Mode 04 e observar o estado limpo.
3
Avaliar Hipótese com IA Experimente a funcionalidade 'Análise com IA'. O modelo correlaciona o freeze frame sintetizado (2.840 RPM) com vela de ignição ou bobina avariada.
